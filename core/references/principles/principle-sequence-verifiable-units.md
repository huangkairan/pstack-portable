# Sequence Work into Verifiable Units

When to apply: For multi-step changes and migrations.

Split work into small units with an observable check at the end of each. Show evidence in sequences such as failing test then fix, or baseline then treatment.

Boundary: A planned migration may allow bounded intermediate breakage. Declare the verification units in advance rather than applying both rules mechanically.
