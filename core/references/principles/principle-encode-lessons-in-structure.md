# Encode Lessons in Structure

When to apply: When the same correction appears a second time.

Turn the repeated lesson into an unrepresentable state, lint rule, standard helper, or runtime check; remove duplicate prose reminders once the structure enforces it.

Boundary: Installation does not cause automatic learning. Distinguish one-off notes, repeated patterns worth a skill or check, and system-wide principles. Implement the mechanism.
