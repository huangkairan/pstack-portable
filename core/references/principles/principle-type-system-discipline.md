# Type System Discipline

When to apply: When defining types in a typed language.

Use discriminated unions, branded semantic types, exhaustive matching, and types derived from authoritative schemas. Strengthen types where loose types make operations partial.

Boundary: This is for typed languages and relates to Boundary Discipline and Encode Lessons in Structure. It does not provide an automatic migration tool.
