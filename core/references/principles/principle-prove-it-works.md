# Prove It Works

When to apply: Before claiming completion.

Exercise the real user path from input to output. Inspect a delegate’s actual diff or run results, and retain a rerunnable check when practical.

Boundary: Compilation alone does not prove completion. Missing environment access may leave a real verification boundary.
