先读取 [执行契约](references/contracts.md) 与 [宿主适配](references/host.md)，再按下列流程执行。

# swarm

1. 选择覆盖矩阵、互斥探索分区、竞速或阶段淘汰结构，写清各切片边界、完成条件与汇总方法。设计/代码合成竞赛使用 arena。
2. 从两名 worker 起，预算允许才增加。任务 brief 包含目标、基线、允许写入路径、证据、时限和报告路径。只读调查显式限制为读工具。
3. 通过原生子代理启动；不重叠写路径，避免多个 worker 修改同一索引。确需共享修改由父代理串行整合。
4. 等待并核对产物；竞速获胜后取消其余本任务 worker 并确认状态。失败、超时、未知状态保留在矩阵，不能合并为成功。
5. 输出覆盖表、证据、重叠发现、空白项及结论。有任一必需分区未覆盖则不能宣布任务整体完成。
