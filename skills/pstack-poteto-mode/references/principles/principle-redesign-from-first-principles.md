# Redesign from First Principles

When to apply: When integrating a new requirement into an existing design.

Read affected code and ask how it would look had the new requirement existed from day one. Update types, references, and docs, then deliver incrementally.

Boundary: Redesign does not require one large rewrite; keep the actual change in scope.
